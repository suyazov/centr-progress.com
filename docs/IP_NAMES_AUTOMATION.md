# Автоматические названия ИП — включено 06.10.2026

Цель: после сохранения нового реквизита ИП заполнить только пустые
RQ_COMPANY_NAME и RQ_COMPANY_FULL_NAME из сохранённых Фамилии, Имени, Отчества.
Краткое название: «ИП <полное ФИО>», полное: «Индивидуальный предприниматель <полное ФИО>».

Ограничения: фиксированный портал anoucdpoprogress.bitrix24.ru, российский
шаблон ИП ID3, компании/контакты, активные реквизиты, ИНН из 12 цифр.
ЮЛ, ФЛ, банковские данные, ИНН, сделки, документы и заполненные названия не меняются.
Изменения происходят после сохранения, а не в ещё открытой несохранённой форме.
Предыдущие реквизиты исключаются границей активации; массового исправления истории нет.
Обработчик проверяет новые реквизиты каждые две минуты; неполные ФИО ждёт до 30 минут.

Используется существующий защищённый доступ bitrix24.env, без выпуска вебхука,
новых прав API, внешних справочников или расходов на API. Секреты/ФИО не выводятся
в журнал или Git. Перед записью сохраняется приватная копия реквизита, выполняется
повторное чтение. Изменившийся реквизит блокирует запись. API не предоставляет
атомарное условное обновление: остаётся короткое окно между повторным чтением и записью.
После записи проверяются оба обновлённых значения. Неопределённая запись остаётся
в статусе SENDING и не повторяется автоматически; разбор по защищённому журналу.

Безопасная живая проверка записи из обращения154: названия уже заполнены,
обработчик вернул UNCHANGED и не выполнял update. Проверка записи в production
не проводилась; синтетический адаптер проверяет обновление только двух полей,
повторный запуск, конфликт и неопределённую доставку. Проверено 6 тестов;
проверены unit-файлы и git diff --check.

## Разрешение и активация

Полномочие: автоматически дополнять два пустых названия всех новых ИП в этом
портале после сохранения. Владелец разрешил запуск сообщением «делай». Таймер и обработчик установлены
из release 6d322a69a24af285bbc00ad31d9f1a4cfce50c60. Граница активации: ID2748;
все предыдущие реквизиты исключены. Первый живой запуск: POLL_VERIFIED,
updated=0, pending=0, Result=success, ExecMainStatus=0. Запись в production
ещё не проверена: новых подходящих реквизитов при первом запуске не было.
Статус отправлен в чат ответом159 на обращение154.

```sh
bash deploy/install-ip-names.sh <точный-checkout> <полный-reviewed-SHA>
```

Установка проверяет общий project lock, фиксирует границу новых реквизитов,
сохраняет immutable release, устанавливает service/timer. Состояние и приватные
копии находятся в /var/lib/centr-progress-ip-names, права 0700/0600.

Проверка после установки: один контролируемый тестовый реквизит ИП с синтетическим
ФИО; дождаться запуска и проверить два названия, сохранность остальных полей
и отсутствие повторной записи. Не использовать реальную клиентскую карточку
для проверки записи. Изменение существующего тестового объекта требует точного scope.

Отключение автоматизации:

```sh
systemctl disable --now centr-progress-ip-names.timer
systemctl stop centr-progress-ip-names.service
```

Отключение не откатывает ранее заполненные названия. Восстановление отдельной
записи выполняется только после сверки текущей карточки с её приватной копией.
