### Названия по ИНН

Шаблон реквизитов «Организация» содержит стандартные поля RQ_INN, RQ_COMPANY_NAME и RQ_COMPANY_FULL_NAME.
Проведён один живой сценарий в несохранённой форме новой компании и реквизита на собственном ИНН учебного центра:
1. Ввод в обычное поле «ИНН» оставил оба названия пустыми.
2. Ввод в «Поиск реквизитов», нажатие лупы и выбор найденной организации заполнили оба названия и ИНН.
3. Компания и реквизиты не сохранялись.

Это подтверждает работу поиска в проверенной форме. Отдельная жалоба на иной ИНН, роль сотрудника или другую форму ещё не воспроизведена. Изменять общие настройки для этого результата не требуется.

Инструкция сотруднику: открыть компанию → Реквизиты → Добавить → Организация → **Поиск реквизитов** → ввести ИНН → нажать лупу → выбрать найденную организацию → проверить названия и адрес → сохранить свою карточку. Обычное поле «ИНН» не заменяет поиск.
[Официальная инструкция](https://helpdesk.bitrix24.ru/open/20510916/).

Тест использует синтетические значения полей ФИО, а не реальные данные клиентского ИП. Для клиентского документа по-прежнему необходимы выбранные реквизиты ИП и заполненные ФИО.
