## Подтверждённые результаты

### Сумма QR в счёте Кисловодска

Шаблон 94 «Кисловодск — Счет ФЛ — 16.09.2026» содержит статическую картинку word/media/image1.png. Локальное декодирование показало Sum=500000 (5000 рублей). В исходной картинке нет связи с суммой документа; отсутствует поле PaymentQrCode.

Подготовленная копия заменяет картинку штатным изображением-заглушкой из стандартного шаблона 4 «Счет (Россия)» и назначает имена {PaymentQrCode} обоим узлам wp:docPr и pic:cNvPr. Положение и размер картинки сохранены. Текст, суммы, таблицы и остальные ZIP-части не менялись.

[Документация Битрикс24 о штатном поле PaymentQrCode](https://helpdesk.bitrix24.ru/open/28202602/).
Установленная CRM-версия ещё не проверялась с кандидатом; будущая генерация зависит от корректно выбранных российских банковских реквизитов получателя. Уже созданные документы автоматически не исправятся.

### Названия по ИНН

Шаблон реквизитов «Организация» содержит стандартные поля RQ_INN, RQ_COMPANY_NAME и RQ_COMPANY_FULL_NAME.
Проведён один живой сценарий в несохранённой форме новой компании и реквизита на собственном ИНН учебного центра:
1. Ввод в обычное поле «ИНН» оставил оба названия пустыми.
2. Ввод в «Поиск реквизитов», нажатие лупы и выбор найденной организации заполнили оба названия и ИНН.
3. Компания и реквизиты не сохранялись.

Это подтверждает работу поиска в проверенной форме. Отдельная жалоба на иной ИНН, роль сотрудника или другую форму ещё не воспроизведена. Изменять общие настройки для этого результата не требуется.

Инструкция сотруднику: открыть компанию → Реквизиты → Добавить → Организация → **Поиск реквизитов** → ввести ИНН → нажать лупу → выбрать найденную организацию → проверить названия и адрес → сохранить свою карточку. Обычное поле «ИНН» не заменяет поиск.
[Официальная инструкция](https://helpdesk.bitrix24.ru/open/20510916/).

### Подписант в акте ИП

Общий шаблон 54 «Шаблон Акт ИП» содержит:
{RequisiteRqDirector~Format=#LAST_NAME# #NAME_SHORT# #SECOND_NAME_SHORT#}

В действующем наборе реквизитов «ИП» есть «Фамилия», «Имя», «Отчество»; поля «Ген. директор» в этом наборе нет.
Подготовлен кандидат с заменой одного поля на:
{RequisiteRqLastName} {RequisiteRqFirstName~Format=#NAME_SHORT#} {RequisiteRqSecondName~Format=#SECOND_NAME_SHORT#}

Региональный шаблон 72 «Пятигорск — Акт ИП — 16.09.2026» уже использует эти поля и не изменялся. По сообщению 128 нельзя достоверно установить, какой именно шаблон использовали; дефект общего шаблона 54 подтверждён отдельно. Для проверки нужны выбранный клиентский реквизит типа «ИП» и заполненные ФИО.
